# Pre-registered expectations

Before Phase 1 the manuscript printed 319 orange "illustrative target" values for experiments that had not run. They were removed from the manuscript on 16 October 2026 and are kept here, unchanged, as the expectations fixed before those experiments run:

- `illustrative_targets.py`: the original target values and the quantities derived from them.
- `../docs/preregistered_targets.csv`: every one of the 330 removed values (319 `\est` occurrences and 11 illustrative plot series) with its line in the old manuscript, the experiment it belongs to, the phase that produces the real value, and what happened to it in the manuscript.

How they are used:

1. When an experiment finishes, its real result goes into the paper, whatever it is.
2. The result is compared with the expectation here. If it is clearly worse, the cause is investigated; an improvement to the method is allowed only if it is documented, justified independently of the test data, and the experiment is re-run in full. The comparison and any change are recorded in the phase report.
3. Expectations are never edited after the fact and never printed in the paper.

Field-check (J1) and Riyadh-test-set values are kept for the record only; those experiments were dropped because no data or approval exist.
